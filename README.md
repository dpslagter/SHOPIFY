# SHOPIFY

Scripts en documentatie voor de Shopify Admin API (Suelta, Cupria, Zofia).

- Koppelen van een winkel: [docs/shopify-api-koppelen.md](docs/shopify-api-koppelen.md)
- Token + GraphQL-hulpscript: `scripts/shopify_auth.py` (`python3 scripts/shopify_auth.py check [winkel]`)
- Gegevens staan in `.env` (zie `.env.example`), nooit in git.
